-------------------------------------
LOCAL HTTP HOST ACTIVATION GUIDE
-------------------------------------

(1) API file
- Make sure Ollama LLM is installed
- Go to local project folder
- Activate .venv if used
    - .venv\Scripts\Activate
- command: python -m univorn api:app --host 127.0.0.1 --port 8001

(2) TTS client (KokoroTTS)
- Go to local installed TTS model.
    - cd C:\AI\KokoroTTS
- Activate .venv if is used.
    - .venv\Scripts\Activate
- command: python -m univorn tts_server:app --host 127.0.0.1 --port 8000
